### ORM : Object Relationnal Mapper

Laravel's ORM is called Eloquent! And simply it is a higtly abstract way to interact with SGBD's tables! It allow us to :

- Create / Update
- Retrieve
- Delete

Data from tables

Let's assume we have a `users` tables! Let's reviews some methods to perform some operations :

The class linked to the `users` table is called `User`

### Insert 

Let's assume you want to store a new user who registers to our services!

##### With Eloquent 

```php

// The Hash class is provided by Illuminate\Support\Facades\Hash
$userHashedPassword = Hash::make('user_password_from_request_object');

$userInserted = User::insert([
    'name' => 'FirstName LastName',
    'email' => 'the_new_user_email@company.com',
    'email_verified_at' => now(),
    'password' => $userHashedPassword 
]);

dd($userInserted); // returns true if insert succeeded, false otherwise
// If you want to get a user instance instead, you can use the method create() -> User::create([]);
```

##### SQL equivalent

```sql
INSERT INTO users (name, email, email_verified_at, password)
VALUES ('FirstName LastName', 'the_new_user_email@company.com', NOW(), '$2y$12$yQjG6qBQbBuHOStXZLXwHeLTAK7hsq.V1CsNsLlqH2m2ko07dYUSy');
```

### Mass insert 

##### With Eloquent 

Ex:
You want to import users from an Excel file:

1- You treat the file by batch 

For each batch you can group users informations into a single array! To perform a mass insertion into the table.
The situation that led you to use this method is when you want to 

2- You insert once all that data and backup!

```php

$batchUsers = [
    [
        'name' => 'FirstUserName ...',
        'email' => 'first_user@company.com',
        'email_verified_at' => now(),
        'password' => $userHashedPassword 
    ],
    [
        'name' => 'SecondUserName ...',
        'email' => 'seconf_user@company.com',
        'email_verified_at' => now(),
        'password' => $userHashedPassword 
    ]
];

// Use insert() for simple batch inserts when no unique constraint or conflict column is needed
$usersInserted = User::insert($batchUsers); // returns true if insert succeeded

// Use upsert() only if you want to update on conflict, e.g.:
// User::upsert($batchUsers, ['email'], ['name', 'email_verified_at', 'password']);

```

For more information about the `upsert()` method, click [here](https://laravel.com/docs/11.x/eloquent#upserts)!


### Retrieve something from the database


##### Retrieve everything from the users tables
